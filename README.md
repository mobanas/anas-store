# 🚀 Anas App & Game Store

Welcome to **Anas Store** — a modern, lightweight, and fully customized open-source web application store designed to deliver a smooth and native-like experience for playing web games and running web apps.

---

## ✨ Key Features
- ⚡ **Ultra Fast & Lightweight:** Built using core web technologies (HTML5, CSS3, JS) with zero unnecessary heavy frameworks.
- 🎨 **Sleek & Modern UI:** Responsive dark-themed user interface optimized for both Mobile and Desktop screens.
- 🔗 **Clean URL Architecture:** Structured with folder-based routing (`/app/`) to eliminate ugly file extensions (like `.html`) from the address bar.
- 🌐 **Offline Support:** Designed to run seamlessly offline once packaged or loaded locally.
- 📱 **Cross-Platform Vision:** Ready to be converted into native packages (`.exe` for Windows/Linux, `.apk` for Android) with 0 branding or ads.

---

## 🎮 Included Apps & Games
